# Перенос на другой ПК — что нужно сделать

Скопирован только код + данные (479 файлов, ~38 МБ). `venv` НЕ скопирован
(был на `D:\dev\factorio-ai\venv` на старой машине) — Python-окружения
обычно не переживают перенос между машинами из-за абсолютных путей внутри,
поэтому пересоздаём заново по списку версий ниже.

## 1. Python

Исходно использовался Python **3.12.10** (`D:\Python312` на старой машине).
Поставить тот же минор (3.12.x) на новой машине, затем:

```
python -m venv <любой_диск>\dev\factorio-ai\venv
<диск>\dev\factorio-ai\venv\Scripts\pip install -r requirements_frozen.txt
```

`requirements_frozen.txt` (рядом с этим файлом) — точный `pip freeze` со
старой машины, включая `factorio-draftsman==3.3.1` (обязательно именно эта
версия — на неё завязана вся геометрия экспортных скриптов) и
`torch==2.13.0+cpu` (используется в `tooling/stage2_train.py`,
`tooling/demo_train.py` — CPU-сборка, GPU не требовался).

## 2. Factorio

Нужна лицензия + DLC **Space Age** (использовался для quality="legendary" в
части экспортов). Путь для результатов Lua-команд:
`%APPDATA%\Factorio\script-output\*.json` — читается вручную после каждой
команды, см. правило ниже.

## 3. КРИТИЧЕСКИ ВАЖНОЕ ПРАВИЛО — не менять при переносе

**Никогда не автоматизировать ввод команд в Factorio** (ни `SendInput`, ни
`SetForegroundWindow` + эмуляция клавиш — пробовалось и было явно запрещено
пользователем после сбоев, см. `AUTOMATION.md`, шапка документа). Рабочий
процесс: Lua-команда показывается текстом в чате и кладётся в буфер через
`Set-Clipboard`, пользователь сам вставляет и подтверждает в игровой
консоли, результат читается из `%APPDATA%\Factorio\script-output\*.json`.

## 4. Прочие гочки проекта (см. PROJECT.md/CONTINUE_HERE.md подробнее)

- Не называть переменные алиасами PowerShell (`rd`, `ri`, `del`) — ложно
  блокирует вставку в буфер.
- `LuaWireConnector.connect_to(...)` — через ТОЧКУ, три явных аргумента
  `(target, no_copy_data, defines.wire_origin.script)`. Двоеточие даёт
  ложный `self` (Решение 33).
- `ConstantCombinator` — один порт; прямой `add_circuit_connection` от неё
  должен опускать `side_1`; `bridge()`/`bridge_to()` сами ставят
  `side_1="output"` на первом хопе — нужен промежуточный реле перед мостом,
  если источник — константа (Решение 34).
