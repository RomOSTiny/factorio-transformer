# ТЗ: символьная языковая модель ~6M параметров

21.09.2026

## Назначение

Нужна посимвольная авторегрессионная языковая модель (decoder-only transformer) примерно на 6 млн параметров для генерации простых английских рассказов в духе TinyStories. Обучение — обычное, во float (PyTorch). Исполняться модель будет в специализированном движке инференса со своими ограничениями, из них и вытекает это ТЗ.

Свойства движка, которые нужно учитывать при разработке:

- **Только целые числа int32, фиксированная точка.** Float нет; веса и активации округляются до фиксированного шага (подробно — в разделе «Численные ограничения»).
- **Одна позиция за шаг, с KV-кешем.** Каузальное внимание, контекст фиксированной длины.
- **Только жадная генерация (argmax).** Сэмплинга, температуры, top-k нет, поэтому качество оценивать при жадном выборе.
- **Ограниченный набор операций.** Всё, чего нет в разделе «Архитектура», недоступно.
- **Задержка на символ растёт линейно с числом слоёв и почти не зависит от ширины.** Поэтому предпочтительна широкая и неглубокая модель.
- **Жёсткие потолки:** ширина модели d_model и длина контекста — не больше ~480 каждая, ширина FFN — не больше 1024.

## Архитектура

Архитектура фиксирована: классический pre-LN GPT с ReLU и общими весами эмбеддинга и выхода. Меняются только размеры; любая другая операция — только после согласования.

Обязательно:

- Вход: `x = tok_emb[token] + pos_emb[position]`; позиции — обучаемый абсолютный `nn.Embedding(context, d)`.
- Блок (pre-LN): `x = x + proj(attn(ln1(x)))`, затем `x = x + fc2(relu(fc1(ln2(x))))`.
- Внимание: одна матрица `qkv = Linear(d, 3d)` с bias, порядок разбиения q, k, v; головы — непрерывные куски по head_dim (`view(B, T, H, hd)`); масштаб `1/sqrt(head_dim)`; каузальная маска; обычный softmax; выход `proj = Linear(d, d)` с bias.
- FFN: `fc1 = Linear(d, ffn)`, `ReLU`, `fc2 = Linear(ffn, d)`, оба с bias.
- `LayerNorm(d)` с обучаемыми weight и bias, `eps = 1e-5`: ln1 и ln2 в каждом блоке и финальный `ln_f`.
- Выход: `logits = ln_f(x) @ tok_emb.weight.T` — веса связаны (tied), без bias и без масштабирования логитов.

Запрещено (нет в движке): GELU, SiLU, SwiGLU и любые GLU-варианты; RMSNorm и post-LN; RoPE, ALiBi, относительные позиции; multi-query / grouped-query attention; sliding window; MoE; отдельная (несвязанная) выходная матрица, bias или soft-capping логитов. Dropout можно только при обучении.

Эталонная реализация (менять только размеры):

```python
class Block(nn.Module):
    def __init__(self, dim, heads, ffn):
        super().__init__()
        self.heads, self.head_dim = heads, dim // heads
        self.ln1 = nn.LayerNorm(dim)
        self.qkv = nn.Linear(dim, 3 * dim, bias=True)
        self.proj = nn.Linear(dim, dim, bias=True)
        self.ln2 = nn.LayerNorm(dim)
        self.fc1 = nn.Linear(dim, ffn, bias=True)
        self.fc2 = nn.Linear(ffn, dim, bias=True)

    def forward(self, x, causal_mask):
        B, T, C = x.shape
        q, k, v = self.qkv(self.ln1(x)).split(C, dim=-1)
        q, k, v = (t.view(B, T, self.heads, self.head_dim).transpose(1, 2) for t in (q, k, v))
        att = (q @ k.transpose(-2, -1)) / math.sqrt(self.head_dim)
        att = F.softmax(att.masked_fill(causal_mask, float("-inf")), dim=-1)
        x = x + self.proj((att @ v).transpose(1, 2).reshape(B, T, C))
        return x + self.fc2(F.relu(self.fc1(self.ln2(x))))


class Model(nn.Module):
    def __init__(self, vocab, dim, layers, heads, ffn, context):
        super().__init__()
        self.tok_emb = nn.Embedding(vocab, dim)
        self.pos_emb = nn.Embedding(context, dim)
        self.blocks = nn.ModuleList([Block(dim, heads, ffn) for _ in range(layers)])
        self.ln_f = nn.LayerNorm(dim)

    def forward(self, idx):
        B, T = idx.shape
        x = self.tok_emb(idx) + self.pos_emb(torch.arange(T, device=idx.device))
        mask = torch.triu(torch.ones(T, T, dtype=torch.bool, device=idx.device), diagonal=1)
        for blk in self.blocks:
            x = blk(x, mask)
        return self.ln_f(x) @ self.tok_emb.weight.T
```

## Размер и гиперпараметры

Целевой конфиг: **d_model = 256, 8 слоёв, 8 голов, FFN = 1024, контекст 128, словарь 35** — ровно 6 360 320 параметров (789 760 на слой × 8, плюс 42 240 на эмбеддинги и ln_f). Это верхняя граница бюджета увеличивать можно но не желательно;

Ограничения на любой вариант:

- Всего параметров ≤ 7 млн.
- d_model ≤ 480, FFN ≤ 1024, контекст ≤ 256 (рекомендуется 128).
- d_model делится на число голов, head_dim ≥ 16; число голов на скорость практически не влияет.
- Слоёв ≤ 8: задержка на символ ≈ число слоёв × размер модели.

Допустимые варианты (задержка относительно целевого, контекст 128):

| d_model | слоёв | голов | FFN | параметров | задержка |
| --- | --- | --- | --- | --- | --- |
| 256 | 8 | 8 | 1024 | 6.36 млн | 1.0 (целевой) |
| 320 | 5 | 10 | 1024 | 5.4 млн | 0.56 |
| 256 | 6 | 8 | 1024 | 4.78 млн | 0.58 |
| 224 | 10 | 7 | 896 | 6.05 млн | 1.17 — хуже, слишком глубокая |

Обучение — на усмотрение разработчика; weight decay желателен, он помогает уложиться в численные ограничения ниже.

## Численные ограничения

Модель должна работать при округлении весов до шага 0.001 и активаций до шага 0.01 в целых int32. Движок считает так:

| величина | представление |
| --- | --- |
| веса Linear, эмбеддинги в роли выходной матрицы | целое = round(w × 1000) |
| активации (эмбеддинги на входе, выходы LN, Linear, внимания, остаточный поток) | целое = x × 100, деление с отбрасыванием дробной части (к нулю) |
| LayerNorm γ и β | целое = round(× 100) |
| веса внимания после softmax | шаг 0.0001 |
| exp в softmax | таблица с шагом 0.08 по разности со скором-максимумом; разность больше 16 даёт вес 0 |
| суммы и произведения | int32, переполнение недопустимо |

Отсюда требования к обученной модели (проверять на валидации):

- **Остаточный поток:** RMS по позиции ≤ 20 (жёсткий предел ~28 при d = 256: сумма квадратов в LayerNorm должна влезать в int32).
- **Любая активация** по модулю ≤ 100.
- **Веса:** |w| ≤ 4, |bias| ≤ 20, |γ|, |β| ≤ 10. Значимые веса не должны быть мельче ~0.001, иначе округлятся в ноль.
- **Линейные слои:** для каждого выхода Σ|x_i · w_i| ≤ 10 000.
- **Внимание:** |q·k / sqrt(head_dim)| ≤ 1000.
- **Логиты:** выбор по argmax на логитах с шагом 0.01, при равенстве побеждает меньший индекс.

Проверка устойчивости к квантованию (fake-quant в PyTorch): веса округлить до 0.001, а выход каждого эмбеддинга, LayerNorm, Linear и внимания — до 0.01 (`torch.trunc(x * 100) / 100`). Требования:

- argmax совпадает с float-моделью на ≥ 90% позиций (не менее 2000 позиций валидации);
- val loss с fake-quant хуже float не более чем на 5%.

Точную целочисленную симуляцию движка прогоняет принимающая сторона; fake-quant нужен, чтобы не сдать заведомо несовместимую модель.

## Токенизатор и данные

Токенизация — по символам, алфавит фиксирован: 35 символов, индексы именно в этом порядке.

| индекс | символ |
| --- | --- |
| 0–25 | `a` … `z` |
| 26 | пробел |
| 27 | `.` |
| 28 | `,` |
| 29 | `!` |
| 30 | `?` |
| 31 | `'` |
| 32 | `"` |
| 33 | `-` |
| 34 | перевод строки `\n` |

В Python: `CHARS = list("abcdefghijklmnopqrstuvwxyz .,!?'\"-\n")`.

- Нормализация: текст переводится в нижний регистр; символы вне алфавита (цифры, редкая пунктуация) выбрасываются. Спецтокенов (BOS/EOS/PAD) нет.
- Перевод строки разделяет рассказы и абзацы.
- Данные: английские детские рассказы в духе TinyStories (можно сам TinyStories); обучение на окнах длины контекста.
- Модель должна уметь продолжать текст с любой позиции окна — в том числе от короткого промпта с позиции 0.
- Изменить алфавит можно только по согласованию (до ~60 символов); тогда полный список и порядок сдаются вместе с весами.
